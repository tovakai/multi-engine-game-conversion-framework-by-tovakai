# v0.1.1.0 — Steam Library Integration

Status: development candidate. **Not release-ready: Steam Frame acceptance is
pending.** No public tag or final release has been created. v0.1.0.3 remains
immutable.

The extracted ZIP keeps one `install-to-steam.sh`. It offers guided linking to
the installed original Steam entry for approved native launch contracts, while
retaining live non-Steam registration, duplicate detection and artwork.

**The original Steam game must be installed through Steam on this Steam Frame
before linking is available.** The installer discovers secondary libraries,
checks complete local installations, opens Steam's official installation flow
when needed, and supports rescanning without another transfer.

No original game files are replaced and no running Steam configuration files
are modified. The user pastes generated Launch Options in Steam. Recoverable
records preserve user-supplied prior options; repair and guided restoration are
available on reruns. A matching launch receipt does not prove gameplay, Steam
Input, playtime, achievements or Cloud support.

Optional post-extraction asset deduplication compares backend-selected static
files by size/SHA-256, replaces only identical converted assets with symlinks,
and records recoverable transactions. Experimental Celeste/Stardew XNB
candidates require tested bubblewrap read-only launches; originals are never
modified. Updates/broken links block launching. Standalone asset restoration,
idempotence and measured storage reporting are included. See
[safety contract and mandatory hardware gates](../steam-asset-deduplication.md).
No backend is advertised as safely deduplicated before real-game acceptance.

Initial shared capabilities: Celeste's audited vanilla profile, Stardew's audited
MonoFrame profile, and manifest-identified GameMaker, LÖVE and AGS native packages.
RenFrame, RPGMFrame and Godot shared linking are deferred. Hollow Knight retains
Windows ARM64/ARM64 Proton; STS2 retains its specialized two-stage Steam chain.

See [installation, capability matrix and mandatory device checklist](../steam-library-integration.md).
Direct original-file patching, coordinated on-device compilation and broader
maintenance goals are deferred explicitly in the [reconciled plan](0.1.1-plan.md).
ZIP naming and converter provenance retain the existing convention.

Candidate builds use the existing Windows x64 and native Linux AArch64 builders
and CI checks: identities, license notices, checksums and frozen startup receipts.
Final official artifacts must be rebuilt from the accepted clean tagged commit
after acceptance; candidate artifacts cannot be relabeled as final releases.

Candidate validation: full Windows regression suite **532 passed, 15 skipped**;
focused Linux AArch64 fixture suite on Frame **74 passed**. Separate synthetic
Frame smoke checks exercised guarded execution and actual bubblewrap write
denial with unchanged source bytes and metadata. These results do not establish
real-game hardware acceptance or achievement/playtime support.
