# 0.1.0.3 — Cassette Beasts compatibility and guided FMOD setup

**Cassette Beasts now has tested native ARM64 graphical compatibility on Steam
Frame.** The converter automatically packages a narrow rendering profile for
Cassette Beasts 1.8.3 using the existing Godot 3.5.1 + GodotSteam runtime.
Disappearing terrain textures and flickering sprites are resolved in the tested
configuration, without changing the game resources or rebuilding the engine.

Physical Steam Frame testing of a fresh Windows-GUI-produced ZIP confirmed more
than five minutes of movement, area transitions, battle and save/load without the
graphical corruption recurring. The original game installation remains unchanged.
The profile preserves existing project overrides and packages the launcher and
configuration needed for native execution. Controller compatibility remains a
separate issue; full-game completion and other driver versions are not verified.
See the [rendering evidence and experiment results](../cassette-beasts-rendering.md).

**FMOD-dependent games now share one guided SDK setup.** Celeste and Slay the
Spire 2 show the FMOD download link, required Linux SDK version, archive chooser
and download-folder discovery in the same dialog. A verified selection is
remembered across compatible games, and each backend rechecks its own checksum
requirements. Missing or invalid SDKs keep conversion blocked and the guide open.
Existing STS2 SDK selections remain discoverable.

The current supported requirement is **FMOD Studio API 2.03.15 for Linux**.
Download the SDK from FMOD under its terms; proprietary SDK files are not included
in the converter release. Celeste still produces its complete Frame package on
the conversion host. STS2 still uses its existing PC preparation and Frame-side
finishing workflow; the shared guide does not expand supported game versions.

This release retains the Celeste and Hollow Knight support from earlier releases.
Windows x64 and native Linux AArch64 application downloads are provided with
checksums, source/build identities and license notices. No game content or
proprietary vendor SDKs is distributed in the application archives.

Validation: the combined local Windows suite passed **477 tests, with 4 skipped**.
Cassette's fresh frozen-GUI conversion and physical Frame acceptance are recorded
in the linked evidence. The shared FMOD guide was tested with both real dialog
windows and the owner's checksum-verified SDK; regression coverage checks routing,
invalid-SDK blocking, persistence and per-backend revalidation. Official archives
are built from the matching clean release tag and checked against their embedded
GUI/CLI build identity.
