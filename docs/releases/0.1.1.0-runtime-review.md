# Runtime distribution review for v0.1.1.0

Runtime tags are separate from the application release. Neither runtime is
published by this review. Application publication remains gated by the Frame
acceptance ledger.

## Until Then

The allowlisted bundle contains the native engine, six extensions, license
notices and independently authored rebuild sources. The FMOD vendor runtime,
owner SDK, Valve Steam API binary and commercial game assets are excluded.
The FMOD binding has its own MIT license; this does not grant a license to FMOD
itself. See the [binding upstream](https://github.com/MadFlyFish/fmod-for-godot).

Source review found that `build_public_extensions.py` imported an omitted
`steam_sdk_compat.py`. The helper is now included with the BSD-3-Clause
[GameNetworkingSockets notice](https://github.com/ValveSoftware/GameNetworkingSockets/blob/master/LICENSE).
Its inline functions delegate to genuine Steam networking interfaces.
No successful Steam service or ownership response is fabricated.

The updated archive checksum is
`9b6202719364850f8754ee5d0eeacda59741dafb952a2b1af78bd3c9c1bf945e`.
Only source/notice members and the integrity manifest changed. Existing
converted games do not require reconversion for this source packaging fix.

## Train45

The allowlisted bundle contains the official Godot ARM64 release template,
GodotSteam extension and bundled notices. It excludes game data and Valve
binaries. Its archive checksum remains
`0a5a7c9dede73b96e6c9b3529f28e1111e3b8bcb4e6280671251587cfd23eb52`.
The exporter verifies exact upstream archive inputs and output member hashes.

Godot documents the engine and third-party attribution requirements in its
[license compliance guide](https://docs.godotengine.org/en/stable/about/complying_with_licenses.html).
Both bundles retain the engine license and copyright notices.

## Remaining gates

- Review source provenance and vendor/header distribution conditions before
  publishing runtime assets. Presence of an open-source binding license does
  not establish permission for unrelated vendor SDK content.
- Exported InkCPP, Threen and Steam-extension build scripts passed on Frame
  using the existing pinned dependency cache on 2026-10-15. This is incremental
  native build evidence; a clean full engine/FMOD rebuild remains unverified.
- Provision the runtime-only download assets or embed the verified bundles in
  all three converter artifacts; currently configured download URLs are not
  evidence that public assets exist.
- Rebuild final converter candidates against the updated pinned archive and
  verify notices, identity, checksums and frozen conversion receipts.

Private game ZIPs, owner SDKs and installed Steam binaries must never be
uploaded as runtime or converter release assets.
