# 0.1.0.1 — Experimental Hollow Knight conversion

This revision adds UnityFrame to the regular Windows x64 / Linux ARM64 converter
GUI and CLI. It supports the exact tested Steam Windows Hollow Knight edition
on Unity **6000.0.61f1**, using a matching **Windows ARM64 Mono player under ARM64
Proton** on Steam Frame. Existing engine backends retain their Linux-native
runtime and packaging paths.

## Added

- Exact-source inspection gates the game/Steam assemblies, native plugin
  identities, Unity version and managed IL flags. Other Unity exports and
  IL2CPP-only games remain unsupported.
- The GUI enables Convert for the tested profile. Unity player and Steam/DXVK
  bridge archives download automatically, verify SHA-256, and reuse the cache.
- The copied game uses its existing Unity Input System backend through three
  exact-assembly patches. The original installation is preserved.
- Output is explicitly `*-windows-arm64-proton.zip`, with dedicated-prefix
  launching, automatic discovery of supported installed ARM64 Proton, the
  standard Steam shortcut installer and optional official Steam artwork.
- Live prefixes, saves and runtime logs are excluded from repackaged ZIPs.
  Forced rebuilding refuses outputs containing a live prefix/saves.
- Unity inspection also reports engine metadata, Mono/IL2CPP evidence and
  native-plugin architectures for unmatched exports without declaring them
  convertible.

## Install and use

Download the application archive for the converter host:

- `multi-engine-game-conversion-framework-by-tovakai-0.1.0.1-windows-x64.zip`
- `multi-engine-game-conversion-framework-by-tovakai-0.1.0.1-linux-aarch64.tar.gz`

Extract the entire application folder and run its executable. On Windows, drop
your installed Hollow Knight folder into the GUI and click Convert. No manual
runtime selection is required for the tested edition. The CLI supports the same
profile through the normal `inspect` and `build` commands.

On Frame, install a supported **ARM64 Proton 11.0** through Steam, extract the
converted game package and run `./install-to-steam.sh`. The launcher discovers
`proton-11.0-2c-arm64` or `proton-11.0-2e-arm64` and manages its own prefix.
Keep compatibility overrides disabled for the package's shell launcher.

The game package is approximately **1.2 GB compressed / 5.24 GB extracted**.
FrameDrop versions with a 4 GiB unpacked ZIP cap require a folder transfer;
ordinary extraction is supported. The application archives contain no game
assets or proprietary Unity player binaries. Those runtime components are
downloaded on the conversion host from their pinned sources.

## Validation and limits

On Steam Frame with `proton-11.0-2e-arm64`, the user confirmed the menu,
controller movement/jumping, audio, bench saving and successful Continue with
controller input after quit/relaunch. The frozen Windows GUI converted the
real installation; its generated package installed its Steam shortcut and
four artwork slots and launched through Steam with automatic Proton selection.
Menu/controller navigation from that shortcut were user-confirmed.

Loaded Unity, Mono, DXVK and Steam PE components were pure ARM64; the Steam
Unix half was AArch64 ELF. No FEX mappings were present in the game process.
The native binaries and patched assembly in the GUI package matched the
playtested copy byte-for-byte. The focused integration/regression suite passed
110 tests before release preparation.

**The profile remains experimental.** Vibration, controller hotplug,
achievements and longer gameplay/scene coverage still need testing. This is
not support for every Hollow Knight update, modded installation or Unity game,
and no performance improvement is claimed.
