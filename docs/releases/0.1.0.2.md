# 0.1.0.2 — Celeste

Adds an experimental native Linux ARM64 conversion profile for the vanilla
Steam Windows XNA edition of **Celeste 1.4.0.0**. The converter detects its
verified source assemblies, prepares a separate copy using FNA 23.10 and
.NET 8.0.31, and produces the normal Frame package and Steam installer.

The automatically downloaded, checksum-verified Celeste runtime SDK supplies open graphics/audio libraries and
Windows/Linux preparation tools. Obtain **FMOD Studio API 2.03.15 for Linux**
separately from FMOD; select its archive with `--fmod-sdk`, place it in Downloads,
or set `MEGCFBT_CELESTE_FMOD_SDK`. Proprietary FMOD libraries are added only to the
owner's converted copy. The original Steam installation remains untouched.

Steam Frame prototype testing confirmed menu display, music, movement, jumping,
climbing, dashing, saving and loading after relaunch with the Frame controllers.
An external 8BitDo gamepad also worked. Launch through the installed Steam
shortcut and select the desired primary controller in Steam when multiple
controllers are connected.

Everest, mods and other Celeste editions require separate profiles. Full-game
completion, achievements and Steam Cloud are not verified. This release also
fixes native package staging on Windows so output files inherit normal parent
folder permissions.

The full Windows test suite passed: **447 passed, 3 skipped**. The frozen Windows
GUI completed a real Celeste conversion through its drop handler and Convert
button. The converter-generated ZIP installed normally in Steam, and the owner
confirmed gameplay, audio and save/reload using that installed copy. The public
runtime passed real download/checksum/cache validation, and the CI-built frozen
Windows GUI completed Celeste conversion using automatic runtime provisioning.
Windows and Linux CI build, test and frozen-startup checks passed.

This release also adopts shared build identities and conversion provenance:
untagged builds display their development identity and commit, while a clean
matching release tag produces the public version. Packages record the converter
and packager identities. Existing releases and converted games remain readable.
Machine-readable build information prints valid JSON at every terminal width.
