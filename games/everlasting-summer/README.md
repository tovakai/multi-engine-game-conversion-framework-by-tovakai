## Observed behavior

The original release was included in the 23-package report. A separate Ren'Py 8 beta had initial gameplay confirmed. The historical user report lists a working package but does not provide a separate full-playthrough or per-title save/load log.

## Scope and limitations

Original 7.4.11 edition requires explicit full-engine 7.5.0 fallback; do not confuse beta and original distributions. Mods and full completion unverified. Hardware reports in this index were **not necessarily rerun with the exact v0.1.0.3 converter binary**. The v0.1.0.3 label denotes the scope of this catalog, not a claim that every old test was repeated.
