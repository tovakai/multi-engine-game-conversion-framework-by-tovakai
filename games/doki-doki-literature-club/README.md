## Observed behavior

Included in 23 reported working packages; independently documented menu, audio, input, quit and relaunch on Steam Frame.

## Scope and limitations

Original DDLC only, **not DDLC Plus**. Poem game, later acts, character-file operations and mods require deeper validation.

This entry describes **evidence available when converter v0.1.0.3 shipped**. Earlier game tests were not necessarily repeated against the exact v0.1.0.3 binary. Successful detection or packaging alone is not a gameplay pass.
