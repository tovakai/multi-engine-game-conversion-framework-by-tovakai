## Recorded result

Historical initial conversion failed because the old detector did not recognize this build. Repository documentation says the 8.0.3 migration/profile was extended to non-HD and Windows frozen GUI conversion was subsequently checked.

## Limitations and current release scope

**No new physical Steam Frame gameplay pass recorded** for the non-HD release. Keep separate from the HD package, which was reported working. This record includes results known by the **v0.1.0.3** release, not a blanket promise of v0.1.0.3 end-to-end gameplay verification.
